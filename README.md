# Community Bot

Telegram-бот для пользовательского комьюнити. Проект находится на стадии формирования требований и архитектуры.

## Текущее состояние

- Создано изолированное рабочее пространство.
- Подключён общий контекст и безопасные правила Telegram из проекта `jarvis`.
- Для проекта выделено отдельное хранилище MemPalace.
- Технологический стек пока намеренно не выбран: сначала фиксируем задачи бота, роли и сценарии.

## Структура

- `docs/PROJECT_CONTEXT.md` — цели, границы и подтверждённые требования.
- `docs/ARCHITECTURE.md` — исходные архитектурные принципы.
- `docs/DECISIONS.md` — журнал принятых решений.
- `src/` — будущий исходный код.
- `tests/` — будущие автоматизированные тесты.

## Работа с Telegram

Для операций с пользовательским Telegram-аккаунтом используется общий инструмент:

```powershell
& 'C:\Users\User\.codex\tools\telegram.ps1' probe
```

Сессии и ключи не хранятся в этом репозитории.

## MemPalace

Выделенное хранилище:

```text
C:\Users\User\.mempalace\palaces\community_bot
```

Документация репозитория остаётся источником истины, а MemPalace используется как поисковый индекс.
