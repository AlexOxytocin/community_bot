# Журнал решений

Этот файл сохраняет ранние решения проекта. Новые структурные и сквозные решения оформляются отдельными ADR в `docs/adr/`; записи не удаляются и не перенумеровываются.

## 2026-07-16 — Изолированная память проекта

Решение: использовать отдельный MemPalace `community_bot`, не смешивая его данные с хранилищем `flatscanner`.

Причина: проекты имеют разные предметные области, требования доступа и жизненный цикл знаний.

## 2026-07-16 — Переиспользование Telegram-инфраструктуры

Решение: использовать каноническое подключение Telegram из `jarvis` для разрешённых операций с пользовательским аккаунтом и не копировать его сессию или ключи.

Причина: единый источник авторизации уменьшает риск рассинхронизации и утечки секретов.

## 2026-07-16 — Отложенный выбор набора технологий

Решение: не выбирать язык, библиотеку, базу данных и способ размещения до описания функций первой версии.

Причина: технические решения должны следовать из реальных сценариев, нагрузки и требований к эксплуатации.

## 2026-07-16 — Интеграция Jira через MCP

Решение: работать с проектом Jira `CB` через установленный Atlassian Rovo MCP, не создавая локальную API-интеграцию и не сохраняя токены в репозитории.

Причина: MCP уже предоставляет контролируемый доступ на чтение и запись и уменьшает объём секретов, которыми должен управлять проект.

## 2026-07-16 — Русский язык документации

Решение: использовать русский язык для смысловой документации, коммуникации в Jira, планов, отчётов и проверок; английский оставить для технических идентификаторов и интерфейсов времени выполнения.

Причина: единый язык уменьшает неоднозначность и делает проектные материалы пригодными для владельца проекта и будущих участников.

## 2026-07-16 — Процесс агентской разработки

Решение: использовать Jira как основной источник задач, ограниченную область изменений, независимую проверку, передачу результата с доказательствами и ограниченные агентские роли.

Причина: эти принципы повышают воспроизводимость разработки без преждевременной инфраструктурной сложности.
