# Community Bot MVP — документация

Этот каталог содержит переносимый пакет требований для первой версии закрытого сообщества взаимной помощи в Telegram.

## Цель MVP

Проверить, способны ли участники регулярно создавать ограниченные задания, выполнять задания друг друга и возвращаться в систему благодаря понятной экономике, прогрессу и репутации.

MVP не должен доказывать, что можно построить большую социальную сеть. Он должен проверить один цикл:

```text
регистрация → создание задания → принятие → выполнение → подтверждение
→ начисление кредитов и опыта → повторное участие
```

## Приоритет источников

Если документы противоречат друг другу, использовать следующий порядок:

1. `11_DECISIONS_AND_OPEN_QUESTIONS.md`.
2. `01_PRODUCT_REQUIREMENTS.md`.
3. `02_DOMAIN_RULES.md`.
4. `TECH_STACK.md` и принятые ADR для технических решений.
5. Остальные документы.

Материальные изменения правил должны сначала фиксироваться в журнале решений, а затем отражаться в связанных документах.

Текущая реализация включает публикацию заданий и атомарный цикл
`принять → отправить версии результата → подтвердить/частично подтвердить/
отклонить → открыть спор`. Доставка напоминаний, административное решение спора,
статистика и итоговая регрессия развиваются следующими задачами MVP.
