# Документация Community Mini App

## Живые документы

- [Контекст продукта](PROJECT_CONTEXT.md) — цель, текущий этап и открытые вопросы.
- [Архитектура](ARCHITECTURE.md) — границы runtime и ответственность слоёв.
- [Разработка](DEVELOPMENT.md) — локальный запуск и проверки.
- [Jira-lite](JIRA_WORKFLOW.md) — планирование и фиксация работы.
- [Принципы](DEVELOPMENT_PRINCIPLES.md) — устойчивые инженерные правила.
- [MVP](mvp/README.md) и [Release 2](release-2/README.md) — требования продукта.
- [ADR](adr/README.md) — история долговременных решений.

Корневые `README.md` и `AGENTS.md` остаются точками входа. Новые документы не
создаются, если информация естественно помещается в один из файлов выше.

## Исторические материалы

Каталог `tasks/` и заменённые ADR сохраняют доказательства прошлых задач, но не
задают текущий процесс. Старые pilot/release runbooks используются только после
явной проверки их актуальности в release-задаче.
