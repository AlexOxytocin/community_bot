# Контекст и стоимость работы Codex

Статус: упрощено 2026-08-24.

- Автоматически активен только корневой `AGENTS.md`.
- Остальные документы читаются по релевантности, а не пакетно.
- По умолчанию работает один агент на `medium` reasoning.
- Субагенты, независимые reviews и полный repository scan требуют прямого
  основания в запросе или риске.
- Tool output передаётся в компактном виде: вывод команды, необходимый для
  решения, а не полный журнал процесса.
- При росте контекста задача не расширяется; результат фиксируется и работа
  продолжается в свежем task только если это действительно нужно.

Числовой budget, который runtime не способен аппаратно остановить, не должен
называться исполняемым gate. Фактические лимиты тарифа и клиента остаются
границей runtime.
