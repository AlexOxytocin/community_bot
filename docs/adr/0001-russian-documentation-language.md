# ADR-0001 — Русский язык смысловой документации

**Статус:** Принято

**Дата:** 2026-07-16

## Контекст

Проект ведётся русскоязычным владельцем и использует Jira, документацию в git и агентские артефакты как долговременную рабочую память. Смешение русского и английского в смысловых объяснениях ухудшает читаемость и проверку.

## Решение

Русский является обязательным языком документации, текстов в Jira, планов, отчётов и артефактов проверки. Английский сохраняется для исходного кода, технических идентификаторов, полей API и базы данных, ключей конфигурации, переменных окружения, логов, сообщений об ошибках во время выполнения, путей, команд и точных внешних значений.

## Рассмотренные альтернативы

Полностью английская документация отклонена: она не даёт преимуществ на текущем составе участников и увеличивает стоимость проверки. Свободное смешение языков отклонено из-за дрейфа терминологии.

## Последствия

- Проектные материалы единообразны.
- Перед публикацией в Jira нужна языковая финальная проверка.
- Технические идентификаторы не переводятся и могут оставаться английскими внутри русского текста.
