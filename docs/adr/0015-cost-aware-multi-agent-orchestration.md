# ADR-0015: Cost-aware multi-agent orchestration

- Status: Superseded
- Superseded: 2026-08-24
- Replacement: root `AGENTS.md` and `docs/AGENT_WORKFLOW.md`

## Решение

Кастомный проектный оркестратор `community_bot.orchestration.v2` выведен из
эксплуатации. Он дублировал штатный Codex, создавал обязательные роли, артефакты
и reviews для задач любого размера и ссылался на budget, который не имел
runtime-enforcement.

Проект возвращён к нативному Codex: один агент по умолчанию, три уровня риска,
условное чтение документации и проверки пропорционально изменению. Субагенты
используются только по прямому запросу пользователя.

## Последствия

- Удалён активный каталог `agents/` и его self-validation test.
- Jira/branch/PR/final-review больше не являются универсальными gates.
- Исторические task artifacts остаются историей и не задают новый процесс.
- Возврат старого контура требует отдельного ADR и доказательства, что новый
  runtime-enforcement существует и измеримо улучшает результат.
