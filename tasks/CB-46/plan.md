# CB-46 — компактный каталог участников

## Контекст

Пункт меню `Участники` сейчас отправляет отдельную карточку на каждого active-участника. Это плохо масштабируется даже на пилотных объёмах: при 500+ людях пользователь получает поток сообщений вместо управляемого каталога.

## Решение

- Перевести каталог в один компактный Telegram-экран: одна строка на участника, раскрытие строки через inline-кнопку.
- Показывать в строке только публичную safe projection: Telegram username, если он есть, анкетное имя, уровень и агрегированную карму.
- Раскрывать только одну строку на текущей странице; повторное нажатие сворачивает её.
- Держать действия `Профиль` и `Оценить` внутри раскрытой строки, а административные действия показывать только при актуальных правах.
- Делать keyset-пагинацию по серверному запросу, не загружая весь список в память.
- Добавить поиск по публичным полям `telegram_username` и `display_name`.
- Минимальная длина поиска: 3 символа после удаления пробелов и ведущего `@`.
- Не искать по Telegram `first_name`/`last_name`, потому что этих полей нет в публичной карточке каталога.

## Проверки

- Интеграционные тесты для поиска, cursor-пагинации и исключения non-active участников.
- Unit/output-driven тесты для компактного Telegram-экрана, раскрытия строки, callback-кнопок и короткого поискового запроса.
- Документация MVP интерфейса, user flow и privacy-политики.
