# План исправления CB-31

## Цель

Оставить первичный bootstrap детерминированным и безопасным, но добавить
штатный способ без SQL исправить отображаемое имя единственного bootstrap
administrator.

## Решение

1. Сохранить нейтральный профиль первого администратора (`Administrator`,
   `UTC`, пустые необязательные поля) как безопасный first-install результат.
2. Добавить отдельную CLI-команду `community-repair-bootstrap-admin-profile`,
   которая читает Telegram ID и display name двумя строками из stdin, а не из
   process argv.
3. Команда работает только для единственного active administrator с точным
   bootstrap provenance, использует общий advisory gate и существующую
   валидацию имени профиля.
4. Повтор с тем же именем является no-op. Команда не перезаписывает остальные
   поля и не применяется к обычному администратору без provenance.
5. В audit хранить только безопасный факт repair без Telegram ID и значения
   имени; CLI также не логирует пользовательский ввод.
6. Через production Dispatcher проверить карточку, участников и leaderboard
   после UTF-8 repair.

## Граница

Новых таблиц, миграций и зависимостей нет. Полный общий прогон выполняется в
CB-29 после слияния всего bug-пакета.
