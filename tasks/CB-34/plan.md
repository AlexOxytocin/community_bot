# CB-34 — план автоматического показа меню после одобрения

## Цель

После первого успешного одобрения анкеты автоматически уведомить участника и
показать каноническое главное меню, не заставляя его вручную отправлять `/start`.

## Решение

1. В одной транзакции с новым переходом `pending → active` создать уникальное
   outbox-событие `registration.approved` для целевого участника.
2. Материализовать событие существующим notification worker с повторами при
   временных ошибках Telegram.
3. Для allowlisted-типа `registration.approved` отправить текст успешной
   регистрации и канонический `main_menu_markup()`.
4. Не создавать новое событие при exact replay или повторном одобрении уже active
   участника.
5. Закрепить атомарность, адресата, текст, клавиатуру и отсутствие дубля
   интеграционным тестом.

До одобрения главное меню не показывается: ручная модерация остаётся обязательной.

## Проверка

- целевой интеграционный тест registration transport;
- полная регрессия, Ruff format/check и `ty`;
- production deploy одного immutable image;
- живой Telegram-сценарий: pending анкета → admin approval → автоматическое меню
  в чате участника.
