# CB-34 — план проверки

1. Завершить анкету приглашённого пользователя и убедиться, что до одобрения он
   видит только ожидание проверки.
2. Одобрить анкету администратором и проверить исходящее сообщение участнику:
   «Регистрация подтверждена. Главное меню уже доступно.» с полной клавиатурой.
3. Повторить тот же Telegram update и убедиться, что второе меню не отправлено.
4. Убедиться, что администратор получает подтверждение, а inline-кнопки заявки
   удаляются.
5. После deploy повторить шаги 1–2 через живую Telegram-сессию и сохранить ID и
   время сообщений в отчёте.
