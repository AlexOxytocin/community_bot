# CB-44 — compact bugfix note

**Уровень риска:** 1B.

**Симптом:** публикация заполненной карточки отклоняется общим Telegram-alert
«Не удалось обработать задание», поэтому автор не понимает, какое поле нужно
исправить.

**Причина:** при резерве 6 кредитов и доступном балансе 4 экономика корректно
выбрасывает `InsufficientBalanceError`, но общий transport-мэппинг не отличает
эту ожидаемую доменную причину от остальных ошибок.

**Правка:** для `InsufficientBalanceError` добавлено отдельное безопасное
сообщение: кредитов недостаточно, нужно уменьшить награду или количество
исполнителей. Внутренний текст исключения, идентификаторы и данные карточки не
раскрываются. Правила экономики и атомарность публикации не изменяются.

**Проверка:** output-driven тест проходит реальный Telegram callback публикации
через fake Bot API и PostgreSQL, подтверждает новый alert, отсутствие созданной
карточки и сохранение текущего черновика в `preview`. Unit-тест подтверждает
отдельный текст для недостаточного баланса и общий безопасный текст для прочих
ошибок. Расширенный набор создания, редактирования и публикации: 46 passed.
Ruff, ty, format и `git diff --check`: успешно. Независимая diff-проверка:
`APPROVED`, замечаний P0–P2 нет.

**Остаточный риск:** пользователь по-прежнему не сможет опубликовать карточку,
если требуемый резерв превышает баланс; это ожидаемое доменное ограничение.
После merge и deployment обязательна проверка фактического alert в живой
Telegram-сессии.
