# CB-61 — эскалация проблемы

Режим: `review_cycle`.

## Проблема

План дважды не прошёл независимую проверку. Единственная оставшаяся причина —
ключевые начальные значения центральной политики и карта ролей не были выбраны
до реализации.

## Воспроизведение

- [Первая попытка](reviews/plan/attempt-01.md)
- [Вторая попытка](reviews/plan/attempt-02.md)
- Канонический текущий вердикт: `plan-review.md`.

## Попытки решения

| Итерация | Действие | Результат | Вывод |
|---|---|---|---|
| План 1 | Заданы цели и общая структура | Не пройдено | Не хватало схемы, state machine, тестов и freeze gate |
| План 2 | Добавлены схема, автомат, проверки и CB-50 gate | Не пройдено | Типы есть, конкретные значения не выбраны |

## Вероятная причина

Стремление не дублировать нормативные числа было применено слишком рано:
будущий runtime source of truth ещё не существовал, а план не зафиксировал
проверяемое решение, которое должно попасть в него.

## Варианты решения

- Оставить выбор значений исполнителю — отклонено как обход plan review.
- Создать второй исполняемый candidate config — отклонено как дублирование.
- Зафиксировать точные planned initial values в task plan, затем единожды
  реализовать их в `agents/config.yaml`, который станет единственным runtime
  source of truth — выбрано.

## Рекомендация

Одним изменением дополнить plan exact mapping, keys, values, units и bounds.
После этого выполнить одну полную post-escalation проверку.

## Требуемое решение

Post-escalation review не одобрил пакет из-за второго runtime-источника
execution budgets. Автоматический цикл был остановлен. Владелец решил:
«глобальные бюджеты канонические». Исправленный план разделяет global runtime
policy и project-specific policy; следующая проверка оценивает новое
owner-approved решение, а не является ещё одним обычным retry.

## Финальная проверка реализации

Фаза final review дважды получила `Status: changes_requested`:

- [попытка 1](reviews/final/attempt-01.md) выявила неполную drift-защиту graph,
  routes, consumers и continuation refs;
- [попытка 2](reviews/final/attempt-02.md) подтвердила закрытие первого пакета,
  но выявила локальную копию `decision_owner` и неисполняемый placeholder в
  validation command.

В соответствии с `review_retry_policy` выполняется одно консолидированное
исправление: `decision_owner` остаётся только глобально, project policy хранит
точный ref, global validator проверяет значение и negative mutation, а
validation command самостоятельно разрешает путь через Windows UserProfile.
Следующий final review является post-escalation проверкой. Если он не будет
одобрен, дальнейшие автоматические исправления запрещены до решения владельца.
