# CB-39 — план

## Цель

Закрепить обязательный Jira-first процесс: баги, функции, пользовательские
истории, изменения runtime, workflow и процесса разработки не реализуются без
задачи Jira `CB` и ветки `task/<ISSUE-KEY>`.

## Область

- обновить канонические правила проекта;
- обновить процесс агентской разработки и Jira workflow;
- обновить конфиги и инструкции `developer`/`final-review`;
- уточнить ADR-0004 и ADR-0010 так, чтобы уровень `1B` сохранял Jira-задачу и
  ветку задачи;
- закрепить постоянный маршрут задачной ветки до PR и merge при успешных gates;
- привести текущую рабочую ветку к `task/CB-39`.

## Не входит

- автоматическое комментирование каждой локальной команды в Jira;
- ослабление требований к закрытым gates для merge, финального `Done`,
  Telegram-действий и других внешних изменений;
- публикация секретов или приватных Telegram-данных.

## Проверки

- `git diff --check`;
- YAML parse для изменённых конфигов;
- поиск старых формулировок, где fast lane мог идти без Jira;
- проверка текущей ветки.
