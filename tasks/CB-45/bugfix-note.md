# CB-45 — compact bugfix note

**Уровень риска:** 1B.

**Симптом:** групповая карточка после выполнения одного из нескольких слотов
получает статус `partially_completed`, исчезает из активных заданий автора и не
позволяет завершить набор. Резерв незаполненных слотов остаётся удержанным до
дедлайна.

**Причина:** фильтр активных заданий не включает `partially_completed`, кнопка
завершения набора скрыта для этого статуса, а прикладной метод отмены принимает
только `published`, хотя дальнейшая логика уже корректно считает занятые и
свободные слоты.

**Правка:** показывать `partially_completed` среди активных карточек только при
наличии свободных слотов, разрешить автору действие «Завершить набор» и
пропустить этот статус в существующий атомарный сценарий закрытия. Сценарий
возвращает резерв только свободных слотов, сохраняет оплаченные назначения и
переводит карточку в `closed_for_new_performers`. Терминальная карточка без
свободных мест остаётся в завершённых разделах и повторно не открывается.
Постраничное дочитывание применяется до фильтрации смешанного статуса, поэтому
подходящие карточки не теряются за первой двадцаткой результатов.

Первая live-проверка после deployment выявила оставшийся transport-разрыв:
callback и команда отмены по-прежнему отклоняли `partially_completed` до вызова
исправленного сервиса. Оба пути синхронизированы с сервисным правилом; callback
показывает отдельное подтверждение возврата свободного резерва. Командный путь
не зависит от видимости завершённого test-run: права и состояние проверяет сам
атомарный прикладной сценарий.

**Проверка:** интеграционный тест проводит реальную отправку результата, полное
подтверждение и выплату по одному из двух слотов, затем закрывает оставшийся
набор и подтверждает возврат ровно одной награды, сохранение оплаченного
назначения и итоговый статус. Отдельный сценарий подтверждает отказ при нулевом
числе свободных слотов. Unit-тесты проверяют разделение карточек между активным
и завершёнными разделами и условную видимость кнопки завершения.
Расширенный прогон: `68 passed`; Ruff, форматирование, ty и `git diff --check`
успешны. Независимое повторное ревью: `APPROVED`, замечаний P0-P2 нет.
Для transport-дополнения отдельно успешно пройдены `36` затронутых сценариев,
включая output-driven callback и командный путь; delta-review повторно
`APPROVED`, замечаний P0-P2 нет.

**Остаточный риск:** отображение считает занятыми все неотменённые назначения,
как и прикладной сценарий закрытия. Экономическая операция дополнительно
защищена проверкой числа свободных слотов и идемпотентным ключом возврата.
