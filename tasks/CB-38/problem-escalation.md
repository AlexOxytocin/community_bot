# CB-38 - эскалация проверки плана

Два последовательных review выявили неполные доказательства безопасности ускоренного
release. Противоречия в продуктовой цели нет; проблема была в точности операционных
контрактов.

Принято одно консолидированное исправление: доказуемый порядок workflow runs, свежесть
heartbeat относительно начала deploy, pinned SSH host verification и однозначная связь
PR CI provenance с actual merge commit. Дополнительные частичные циклы не допускаются:
следующий отрицательный review блокирует реализацию до решения владельца.

## Финальная проверка

Две попытки final review потребовали сначала независимую protected Environment boundary,
уникальную runtime identity и поведенческие тесты, затем выявили небезопасные фактические
права `0777` у server deployment package. Последнее консолидированное исправление
переносит trusted runner в root-only `shared/bin` и проверяет ownership/mode fail-closed.
Следующий отрицательный final review требует остановки и решения владельца.
