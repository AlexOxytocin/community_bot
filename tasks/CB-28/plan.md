# CB-28 — план исправления административного меню

## Причина

Главное меню не содержит входа в администрирование, а callback «Заявки» выводит
только имена. Рабочая выдача карточек и решения уже существует в registration
router, но navigation вызывает другой неполный путь.

## Изменения

1. Добавить кнопку `Администрирование` в главное меню и направить её в
   существующий active-administrator gate.
2. Направить пункт `Заявки` на существующий registration presenter вместо
   отдельного списка имён.
3. Усилить production Dispatcher тест: следующая команда/callback берётся только
   из предыдущего ответа Bot API, затем проверяется однократное одобрение.
4. Обновить пользовательскую документацию и отчёт задачи.

## Границы

Без новой админ-панели, схемы БД и прикладного сервиса. Полная регрессия MVP не
повторяется; обязательны целевой Telegram/PostgreSQL сценарий, Ruff, ty, CI и
production smoke.
