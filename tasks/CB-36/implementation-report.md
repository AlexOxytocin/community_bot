# CB-36 - отчёт о реализации

## Результат

В разделе «Мои задания» автор видит кнопку «Отменить» у собственного
опубликованного задания. Отмена выполняется в два шага: первый callback только
показывает подтверждение, второй вызывает существующий application service
отмены и возврата зарезервированных кредитов.

## Исправленная причина

Доменная операция отмены уже существовала, но Telegram-интерфейс предоставлял
её только через команду `/task_cancel <UUID>`. Карточка не показывала UUID и не
содержала действия, поэтому обычный пользователь практически не мог отменить
своё задание.

## Гарантии

- кнопка доступна только для авторского задания в статусе `published`;
- первый callback не меняет статус, баланс, транзакции, аудит, outbox или
  processed updates;
- право автора повторно проверяется на application-уровне при подтверждении;
- возврат резерва идемпотентен и выполняется ровно один раз;
- чужая или устаревшая кнопка не обходит проверки состояния и владельца;
- задание с историей назначения нельзя отменить, пользователь получает ясную
  причину;
- callback доступен только в личном чате и укладывается в лимит Telegram 64 bytes;
- у community-задач и задач в терминальных состояниях кнопка отсутствует.
