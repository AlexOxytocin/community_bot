# CB-96 — визуальные evidence

## Нормативные design-артефакты

Полный UI board, карта переходов, coverage и split-экраны находятся в
`../design/`. Они документируют все `103` UI screen/state ID, `17` no-UI
контрактов, `26` capabilities и `128` продуктовых переходов.

## Фактический runtime

Девять отдельных PNG в `runtime/` показывают ключевые экраны фактического
Mini App при viewport `375×812`:

- `T01` — каталог;
- `T03` — полная карточка задания с критериями приёмки;
- `M01` — мои задания;
- `P06` — собственный профиль без лидерборда;
- `S01` — очередь кейсов;
- `T05` — редактор задания с solo/group и полями движка;
- `P01` — поиск и карточки участников;
- `P02` — карточка участника и доступность оценки кармы;
- `P05` — отдельный лидерборд внутри раздела участников.

Отдельные PNG каждого экрана лежат в `runtime/`. Длинные формы оцениваются
вместе с split-макетами `creation-1/2` и `task-1/2` из `../design/`, поэтому
нижние части не теряются за границей одного мобильного viewport.

Снимки получены Playwright из локального static runtime с dev/test fixtures.
Они не изображают авторитетный production success неподключённых операций.
