# CB-41 — compact bugfix note

**Уровень риска:** 1B.

**Симптом:** при переключении категории заданий меню обновляется, но карточки
предыдущей выдачи остаются в чате и смешиваются с новым списком.

**Причина:** карточки отправляются отдельными сообщениями, а transport не
сохраняет их `message_id`, поэтому при следующем callback обновляет только
сообщение меню.

**Правка:** связать отправленные ботом сообщения текущей выдачи с приватным
чатом; перед переходом к другому разделу удалить прежнюю группу через Bot API.
Страницы архива добавлять в текущую группу, чтобы они удалялись вместе.
Переключения сериализовать по чату, а callback пагинации привязать к случайно
инициализированному поколению выдачи и разрешать использовать только один раз.

**Проверка:** integration/output-driven тест подтвердил вызов `deleteMessages`
с ID предыдущих карточек при смене категории и отсутствие удаления во время
пагинации. `tests/integration/test_navigation.py` и
`tests/integration/test_assignments.py`: 18 passed; unit navigation: 2 passed;
`ruff`, `ty` и `git diff --check`: успешно. Далее обязательны CI, deployment и
живая проверка профилями `default` и `tg-test`.

**Независимая diff-проверка:** `APPROVED`, текущих P0–P2 не обнаружено.

**Риск:** состояние намеренно процессное. Сообщения, отправленные до перезапуска
бота, восстановить через Bot API невозможно; callback старого процесса не
совпадает с новым случайным поколением. Новые выдачи очищаются
детерминированно; временная ошибка удаления не блокирует навигацию. Изменений
схемы БД, экономики и прав нет.
