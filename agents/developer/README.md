# Агент-разработчик

Основная роль для работы с Jira-задачами проекта `CB`.

Роль отвечает за:

- чтение задачи Jira и проверку её готовности;
- подготовку compact bugfix note для уровня `1B` либо плана и пакета источников
  для уровней 2–3;
- ограниченную область реализации в `task/<ISSUE-KEY>`;
- тесты, проверку ключевого сценария и контрольную перепроверку;
- compact diff-вердикт для уровня `1B` либо `implementation-report.md` и
  передачу результата независимому `final-review` для уровней 2–3;
- стандартную недеструктивную передачу Jira → Git → release → deploy в рамках прямого
  поручения на реализацию, с остановкой при failed gate, конфликте или росте риска;
- обновление долговременной документации и MemPalace.

Роль не выбирает технологический стек без требований и не считает собственную реализацию финально одобренной.
