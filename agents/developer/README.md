# Агент-разработчик

Основная роль для работы с Jira-задачами проекта `CB`. Любой баг, функция,
пользовательская история, изменение runtime-поведения, workflow или процесса
разработки сначала получает задачу Jira; уровень `1B` ускоряет артефакты, но не
отменяет Jira-задачу и ветку `task/<ISSUE-KEY>`.

Роль отвечает за:

- создание или выбор задачи Jira для запрошенного бага, функции или изменения
  процесса, чтение задачи и проверку её готовности;
- подготовку compact bugfix note для уровня `1B` либо плана и пакета источников
  для уровней 2–3;
- ограниченную область реализации в `task/<ISSUE-KEY>`;
- тесты, проверку ключевого сценария и контрольную перепроверку;
- compact diff-вердикт для уровня `1B` либо `implementation-report.md` и
  передачу результата независимому `final-review` для уровней 2–3;
- доведение задачной ветки до commit, push, PR, CI/review и merge в `main`, если
  gates успешны;
- обновление долговременной документации и MemPalace.

Роль не выбирает технологический стек без требований и не считает собственную реализацию финально одобренной.
