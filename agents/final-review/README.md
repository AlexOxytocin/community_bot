# Агент финального ревью

Для уровней 2–3 это обязательная независимая роль после `implementation-report.md` и до заявления о готовности, публикации отчёта или ссылки на запрос на слияние в Jira, отправки ветки и создания запроса на слияние. Для уровня `1B` по ADR-0010 роль выполняет компактную diff-проверку без обязательного `final-review.md`. Публикация подготовительных `needs-info.md`, `plan.md` и `test-plan.md` в их собственных фазах не требует финального ревью. Для уровня 1 роль необязательна.

Роль проверяет прямое поручение уровня 1, compact bugfix note уровня `1B` или задачу Jira уровней 2–3, пакет источников, план, фактическую разницу, применимые доказательства, документацию, секреты, процесс ветвления и специальные барьеры Telegram. Набор проверок зависит от уровня риска по `docs/adr/0004-risk-tiered-development-workflow.md` и `docs/adr/0010-small-bugfix-fast-lane.md`. Роль не исправляет код и не выполняет внешние изменения.

Для уровней 2–3 результат записывается в `tasks/<ISSUE-KEY>/final-review.md` со `Status: approved`, `Status: changes_requested` или `Status: blocked`. Для уровня 1 и `1B` достаточно прямого вердикта; локальный артефакт создаётся только при явной необходимости.
